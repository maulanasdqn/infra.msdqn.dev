# Darwin system

System-level nix-darwin settings.

## Manual/man pages disabled

Building the nix-darwin manual is skipped. Its `options.json` is generated by
nixpkgs' `nixosOptionsDoc`, which on current nixpkgs-unstable references the
nixpkgs source path without string context and emits a build-time warning.
Nothing here uses `man darwin-configuration` or `darwin-help`, so it is disabled
outright.

The same reasoning applies to the home-manager manual — see
`../../home/README.md`.

## Single-owner tweaks

A block of settings gated by `enableAggressiveTweaks` (MacBook only). These
change **firmware (NVRAM) boot-args, global power management, and the HID
keymap** — machine-wide effects that would hit every account, which is why they
never apply to the shared Mac mini.

See `../README.md` for the full list of what the flag controls.
