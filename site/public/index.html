How It Fits Together

Layered profiles and per-platform modules, shared where it counts.

.
├── flake.nix            # single entry point for every host
├── hosts/               # workstation · darwin · vps · raspi · wsl · android
├── profiles/            # base → workstation / server (hardened SSH, nginx)
├── modules/
│   ├── nixos/           # boot, desktop, audio, networking, git-sync
│   ├── darwin/          # macOS defaults, homebrew, aerospace, sketchybar
│   └── home/            # home-manager: shared dotfiles, per-OS packages
├── secrets/             # sops-encrypted, decrypted only on target hosts
└── templates/           # devenv project templates: rust · nodejs · laravel

Why This Setup

The properties that make it worth maintaining.

  • Reproducible by construction — a new machine is a clone, a config entry, and one rebuild away from identical.
  • Zero-touch server provisioning — nixos-anywhere takes a blank VPS to a hardened, service-running host over SSH in one command.
  • Secrets done right — sops-encrypted in git, decrypted only on the hosts that need them.
  • Self-healing servers — VPS hosts git-sync their configuration, so the repo is always the source of truth.
  • One editor everywhere — nixvim builds the same Neovim on every platform, plugins pinned by the flake lock.
  • Instant dev environments — devenv templates spin up Rust, Node.js, or Laravel projects with databases via direnv.
